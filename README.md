# RoSim

Conecta tu volante (Logitech G29, G920, G923, G27, G PRO…), el sidestick Airbus Thrustmaster TCA y la palanca de gases a Roblox. Sin zona muerta. Gratis para Windows.

**Web y descarga:** https://rosimpanel.github.io/

- `RoSim.zip`: la app (descomprime y abre `INSTALAR.bat`).
- `version.json`: lo lee la app para avisar de actualizaciones.
- `src/`: código fuente de la app.

Para publicar una versión nueva: sube el número en `src/VERSION`, vuelve a generar `RoSim.zip` y cambia `version` en `version.json`.

RoSim no está afiliado ni respaldado por Roblox Corporation, Logitech ni Thrustmaster.
